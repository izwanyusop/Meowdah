# 🐈 Meowdah.my - Marketplace Kucing Premium Malaysia

Meowdah.my adalah platform marketplace kucing moden bertaraf premium yang direka khusus untuk peminat dan pembiak (*breeder*) kucing di Malaysia. 

Dibina menggunakan teknologi terkini Next.js 16 (React 19), Vanilla CSS, Supabase Realtime, dan dioptimumkan sepenuhnya sebagai **Progressive Web App (PWA)** untuk kelajuan luar biasa pada peranti mudah alih.

## 🚀 Ciri-Ciri Utama Platform
- **Borang Post Ad Canggih:** Canvas image compressor, auto-stripping EXIF metadata (keselamatan GPS), dan watermark automatik.
- **Sembang Masa-Nyata (Realtime Chat):** Komunikasi langsung penjual-pembeli menggunakan Supabase Realtime postgres subscriptions.
- **Monetisasi Premium Booster (FPX):** Integrasi dinamik ToyyibPay & Billplz untuk pakej **Featured Ad** dan **Urgent Ad**.
- **Papan Pentadbiran Admin (Anti-Scam):** Portal moderasi aduan, penggantungan iklan, dan badge pengesahan *Verified Breeder*.

## 🛠️ Tech Stack & Alat
- **Framework:** Next.js 16.2.6 (App Router)
- **Database & Auth:** Supabase
- **PWA:** @ducanh2912/next-pwa
- **Pembayaran:** ToyyibPay FPX & Billplz FPX API
